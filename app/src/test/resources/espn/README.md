# Synthetic sports fixtures

All seven JSON examples were constructed independently for parser tests. Teams, IDs, matchups and schedules are fictional. They contain no downloaded provider response or personal favorites. The field structure exercises the supported public API representation.

Inline parser and migration examples also use constructed events. Real catalog IDs remain only where the behavior under test is a public team mapping or matching rule. Chat tests use invented paper-kite participants and messages, with no copied personal conversation.
