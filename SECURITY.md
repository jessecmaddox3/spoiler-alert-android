# Security policy

## TL;DR

Please report suspected vulnerabilities privately. Do not open a public issue for a vulnerability that could expose notification content or credentials.

Use [GitHub's private vulnerability reporting form](https://github.com/jessecmaddox3/spoiler-alert-android/security/advisories/new) with a concise reproduction, affected version or commit, impact, and any suggested mitigation.

Never include real notification text, account credentials, signing keys, or private device identifiers in a report.
